PROJECT OVERVIEW

About ScamShield

A modular educational prototype for scam detection and scam-stage understanding.

PURPOSE

Detect + explain

ScamShield analyzes suspicious text and links, then presents risk, scam type, stage signals and safety guidance.

STACK

Simple and maintainable

Plain HTML/CSS/JavaScript, Flask, scikit-learn and CSV. No React, Vite, Docker, SQLite or database.

ML PIPELINE

TF-IDF + Logistic Regression

Raw data → cleaning → train/test split → TF-IDF → baseline classifier → evaluation.

SCAM STAGES

From contact to recovery

Initial contact, trust building, urgency, credential harvesting, payment, transaction/investment and recovery manipulation.

Project workflow

User input→Flask→ML + rules→Stage + URL analysis→Risk result
